## 🎯 What is NoxShepherd?

**NoxShepherd** is my personal space for learning and documenting cybersecurity through practical experimentation.

Rather than keeping everything as private notes, this project follows a **learning in public** approach:

```text
Learn
  ↓
Research
  ↓
Build a Lab
  ↓
Experiment
  ↓
Break
  ↓
Understand
  ↓
Document
  ↓
Share
```

The goal is not simply to collect commands or tools, but to understand **why a technique works, how it can be detected or mitigated, and how it can be applied responsibly in an authorised environment.**

## 🧠 Learning Philosophy

Cybersecurity is a field where understanding the fundamentals matters more than memorising tools.

My approach is therefore:

> **Don't just run the tool. Understand what the tool is doing.**

For example, instead of only learning:

```bash
ffuf -w wordlist.txt -u http://target/FUZZ
```

the goal is to understand:

* How HTTP requests are constructed
* How wordlists influence enumeration
* How HTTP status codes are interpreted
* Why false positives occur
* How filtering works
* How the attack could be detected
* How the application could be hardened

Tools are just implementations of concepts.

## ⚠️ Responsible Security

Everything published here is intended for **education, research, and authorised security testing**.

Techniques demonstrated in this repository should only be used against:

* Systems you own
* Dedicated laboratory environments
* CTF platforms
* Intentionally vulnerable applications
* Systems where you have explicit permission to perform security testing

> **With great access comes great responsibility.**

The objective is to learn how systems can be attacked so that they can ultimately be **better protected**.
